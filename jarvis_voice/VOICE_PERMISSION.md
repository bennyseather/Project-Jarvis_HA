# Project Jarvis v5 voice permission record

The bundled `assets/jarvis-v5-reference.wav` is derived from the reference
selected and approved by the Project Jarvis owner for this non-commercial
open-source hobby project. The source creator granted free personal and
open-source use and declared the work to be their own creation. The signed
permission and original correspondence are retained privately by the project
owner rather than published with the repository.

The reference is used only to condition the local Chatterbox engine. It is not
presented as an official Marvel voice, actor performance, endorsement, or exact
replica. Project Jarvis applies its own bounded staccato and synthetic finishing
chain to generated PCM.
