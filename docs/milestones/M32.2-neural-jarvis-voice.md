# M32.2 - Neural Jarvis Voice

Release: 0.23.0

Project Jarvis Voice synthesizes locally with Kokoro-82M through ONNX Runtime.
Four licensed British male voices are exposed through Wyoming and followed by
bounded Jarvis DSP. The model is loaded once, synthesis runs off the event
loop, audio remains in memory, and official Piper is an automatic fallback.

Home Assistant continues to own pipelines, TTS selection, satellites, and
audio routing. Jarvis owns only optional synthesis and voice presentation.

## Acceptance note

Provisionally accepted for continued development using the modified
`bm_daniel` voice. The current result does not meet the intended voice-quality
target or approach the previously approved hosted voice closely enough. Voice
model selection or training remains explicit future work and must be revisited
when a more capable local voice architecture or dedicated AI host is available.
