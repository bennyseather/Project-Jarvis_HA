# Purpose

Introduce one explicitly confirmed, allow-listed Home Assistant state-changing action without giving the language model direct control.

# Decision

M5.8 supports only `light.turn_on` for explicitly configured entity IDs. A model proposal creates a pending action; it never calls Home Assistant immediately. The user must submit an exact confirmation token before Jarvis invokes the typed Home Assistant action adapter.

The token binds action type, entity identifier, and a short expiry timestamp. Any changed, expired, unknown, reused, ambiguous, or missing token is rejected. Pending actions are process-local and contain no credentials. Confirmation is required even for an exact entity reference.

# Boundaries

- `AssistantOrchestrator` validates proposal, allow list, and confirmation token.
- `PendingActionStore` owns one-time pending action lifecycle only.
- `HomeAssistantActionProvider` exposes only `turn_on_light(entity_id)` in this milestone.
- Home Assistant executes the service call and remains the source of truth.
- The LLM proposes an action but cannot invoke the provider directly.

# Acceptance Criteria

- An action proposal returns `requires_confirmation` and makes no service call.
- Only a valid one-time token for the exact configured light executes `light.turn_on`.
- Reused, expired, altered, or unknown tokens never make a service call.
- Non-allow-listed entities and unsupported actions are rejected before a pending action is created.
- Tests use fake providers and cover every non-execution safety path.

# Out of Scope

- Any service other than `light.turn_on`, automation creation, bulk actions, schedules, background execution, voice confirmation, multi-step plans, and persistent pending actions.

# Approval Decisions Required

1. Approve `light.turn_on` as the only initial state-changing action.
2. Approve mandatory one-time, expiring confirmation tokens bound to action and entity.
3. Approve process-local pending actions with no persistence or background execution.
4. Approve allow-listed lights only; all other action proposals are rejected.
