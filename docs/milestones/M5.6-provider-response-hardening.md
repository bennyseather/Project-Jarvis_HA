# Purpose

Harden the real OpenAI proposal adapter and console response rendering for predictable safe operation.

# Decision

M5.6 defines a strict JSON-only proposal envelope, validates it before orchestration, and maps all provider, parsing, and Home Assistant read failures to concise structured results. The console never displays credentials, raw transport messages, tracebacks, or unbounded provider payloads.

The language model may propose only `conversation` and `read_entity_state`; all other output is unsupported. Read failures become unavailable results. This milestone does not add tools, service calls, streaming, or state changes.

# Approval Decisions Required

1. Approve strict JSON-only model proposal output for the read-only slice.
2. Approve concise generic provider failure messages in the console.
3. Approve mapping unavailable Home Assistant entities and transport failures to structured unavailable results.
