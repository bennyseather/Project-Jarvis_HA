# Purpose

Compose the M5.2 read-only assistant into `JarvisApplication` using explicit configuration for allowed Home Assistant entity identifiers.

# Decision

Add an optional `allowed_read_entities` configuration list. During application service initialization, construct the read-only assistant with the existing OpenAI and Home Assistant clients plus this immutable allow list, then store it in the service container.

An absent or empty allow list permits conversation only; every entity-state proposal is rejected. Configuration is validated as a collection of non-empty entity identifier strings. No credentials are added to model input, no entity registry is used for authorization, and no service-call capability is composed.

# Acceptance Criteria

- Application initialization composes `read_only_assistant`.
- Empty or absent configuration denies all entity reads safely.
- Configured entity reads are the only Home Assistant operations reachable from `handle_request`.
- Tests use fake clients and do not contact external services.

# Approval Decisions Required

1. Approve `allowed_read_entities` as the explicit read authorization configuration.
2. Approve deny-by-default behavior for missing or empty configuration.
3. Approve no use of the existing entity registry as an authorization source.
