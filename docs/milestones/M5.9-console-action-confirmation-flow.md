# Purpose

Connect validated generic Home Assistant action proposals to the console through an explicit one-time confirmation flow.

## Implementation Status

Approved and implemented. The console stores the exact pending payload in process memory and accepts only `confirm <token>` for one-time execution.

# Decision

The model may return a typed Home Assistant action proposal. Jarvis passes it to the composed capability gateway, which returns either forbidden or `requires_confirmation` with a human-readable summary and opaque token. The console displays that summary and asks the user to enter the exact token plus `confirm`.

The confirmation call reuses the existing token-bound gateway. It does not accept natural-language assent, partial tokens, altered payloads, background confirmations, or automatic retry. High-impact actions display an additional warning and require the same explicit token flow in this first version.

# Approval Decisions Required

1. Approve console confirmation using the exact opaque token plus `confirm`.
2. Approve generic typed Home Assistant action proposals from the model only after schema validation.
3. Approve no natural-language confirmation parser or background action execution.
