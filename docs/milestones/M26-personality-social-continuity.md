# M26 Jarvis Personality and Social Continuity

Status: complete

Jarvis now has a central, safety-subordinate personality profile: calm,
competent, concise, discreet, warm, and capable of restrained dry wit.
Presentation uses British English and an original refined synthetic voice
identity. It does not imitate Marvel dialogue, a fictional performance, or an
actor's voice.

Explicit preferences are stored as inspectable Jarvis knowledge. Supported
controls include `show personality`, `explain personality`, `address me as
<name>`, `set personality humour off|subtle`, `set personality formality
relaxed|refined`, `set personality verbosity concise|balanced`, `reset
personality`, and `forget personality preferences`.

Personality changes wording only. It never changes facts, Home Assistant state,
permissions, risk, confirmation, execution, privacy, or safety. Humour is
forbidden during failures, safety issues, emergencies, confirmations, and
sensitive topics. Voice timbre remains controlled by the selected Home
Assistant TTS provider; users may select an original British, subtly
synthetic/metallic provider voice when available.
