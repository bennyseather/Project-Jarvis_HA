# Purpose

Establish a consistent way to identify the kind of assistance a user is requesting so that Jarvis can select an appropriate orchestration path.

# Background

EPIC 1 introduces the Context Engine, which must distinguish between requests that need home context, conversational continuity, capability use, or no additional context. Classification supports orchestration without taking over the language model's responsibility for reasoning or Home Assistant's responsibility for home state.

# Functional Requirements

- Identify the request category needed to select an orchestration path.
- Classify requests as INFORMATION, COMMAND, QUERY, AUTOMATION, PLANNING, MEMORY, CONVERSATION, or UNKNOWN.
- Distinguish requests that concern the home from those that do not require home-specific context.
- Identify when a request may require capability discovery, contextual information, or a direct conversational response.
- Preserve the original user request for later stages of the pipeline.
- Update RequestContext to CLASSIFIED when classification completes through the context-oriented interface.
- Provide a classification result that can be used by downstream components without requiring them to reinterpret the request.
- Handle uncertain or unsupported requests safely by selecting a defined fallback path.

# Deliverables

- A request-classification component or module.
- A documented set of request categories and classification outcomes.
- Tests covering supported categories, ambiguity, and fallback behavior.

# Acceptance Criteria

- Incoming requests receive a defined classification outcome.
- The classification outcome is sufficient for downstream orchestration to select a path.
- Ambiguous requests have a documented and consistent fallback outcome.
- Classification does not issue Home Assistant commands or generate final user responses.
- Tests demonstrate the expected treatment of representative request categories.

# Out of Scope

- Executing Home Assistant actions.
- Discovering or invoking capabilities.
- Building detailed home context.
- Persistent memory retrieval or storage.
- Generating the final natural-language response.

# Dependencies

- EPIC 0 documentation and architecture foundation.
