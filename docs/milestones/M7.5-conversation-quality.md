# M7.5 Conversation Quality

Jarvis keeps a small, process-local conversation window so the language model
can understand immediate follow-up requests. The window is bounded by
`conversation.max_messages` (default: 12), is cleared on restart, and is not
written to memory or learning systems.

Entity aliases are optional mappings in `home_assistant.entity_aliases`. An
alias can resolve only to an explicitly allowed read entity. Unknown or
ambiguous references result in a clarification response rather than a Home
Assistant call.

Console responses now map operational outcomes to concise, safe user messages.
They do not expose tokens, provider payloads, or configuration details.
