# M21 Reflective Learning and Companion Continuity

Status: complete

## Outcome

Jarvis can build bounded, inspectable connections between approved durable
memories, surface uncertainty and contradictions, retain explicit interaction
preferences, and remove connected information without retaining deleted
history.

## Architecture

- Home Assistant continues to own entities, services, automations, and state.
- The language model continues to own language understanding and planning.
- Jarvis owns durable memory, validated reflection records, bounded retrieval,
  provenance, consolidation, and natural memory controls.
- Reflection derives only from policy-approved durable memories. It does not
  persist raw chain-of-thought, unrestricted inference, or raw audio.
- Sensitive reflections are excluded from ordinary model context.
- Reflection context is capped at five results by default and ten by
  configuration validation.
- Exact duplicate consolidation preserves the oldest record, combines allowed
  provenance, and hard-deletes redundant records.
- Corrections rebuild reflection state from the replacement value, so obsolete
  information is not retained.
- Jarvis never rewrites its own code, expands permissions, changes safety
  policy, or claims consciousness.

## Capabilities

- Durable relation, uncertainty, contradiction, style, and follow-up records.
- Provenance through source memory and conversation identifiers.
- Explicit style feedback applied as a durable preference.
- Contradictory repeated context produces a clarification and correction path.
- Per-conversation repeated-learning opt-out.
- Natural inspection, provenance, uncertainty, and connected-deletion commands.
- Transactional SQLite schema migration from version 2 to version 3.

## Natural controls

- `What have you learned about me?`
- `Why do you remember about <subject>?`
- `What are you uncertain about?`
- `Show memory connections`
- `Do not learn from this conversation`
- `Learn from this conversation again`
- `Forget everything connected to <subject>`

## Acceptance boundary

M21 does not add autonomous notifications, permission changes, code
self-modification, covert personality profiling, or claims of subjective
awareness. Reflection remains a software capability over inspectable records.
