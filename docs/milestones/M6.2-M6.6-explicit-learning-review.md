# M6.2–M6.6 Explicit Learning Review

## Purpose

Implement explicit, process-local learning proposals with review and management, without automatic learning or a new durable store.

## Design

`LearningProposalManager` accepts only policy-approved proposals. It supports deterministic pending inspection, explicit approve/reject, and cancellation. Approval changes proposal status only; a future user-facing integration must submit any durable output through the existing Memory or Knowledge writers. No proposal is persisted automatically.

## Safety

Sensitive, security, presence, health, credential, Home Assistant state/history, and inferred-behavior sources are rejected. Learning has no Home Assistant execution path and no new datastore.

## Status

Approved and implemented as review-only foundations.
