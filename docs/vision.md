# Vision

## Purpose

Project Jarvis is a persistent AI companion for the home. It extends interactions with Home Assistant by retaining useful context, building home-specific knowledge, and coordinating long-term assistance.

## What Jarvis Is

Jarvis is a persistence and orchestration layer that complements Home Assistant and the language model. It connects long-term memory, contextual understanding, and knowledge of a specific home to make assistance more continuous and useful over time.

## What Jarvis Is Not

Jarvis is not a replacement for Home Assistant, which remains responsible for devices, entities, automations, integrations, and state. It is not a replacement for the language model, which remains responsible for reasoning, language understanding, planning, and general knowledge.

## Core Principles

- Keep responsibilities clear across Home Assistant, the language model, and Jarvis.
- Preserve useful context and memory without duplicating existing platform capabilities.
- Build home-specific knowledge that supports relevant, dependable assistance.
- Prefer simple, understandable designs that can evolve deliberately.

## Long-Term Goals

Jarvis will provide durable memory, rich context, home knowledge, event awareness, and orchestration for natural conversations and helpful assistance. It will evolve alongside Home Assistant and the language model while respecting their distinct responsibilities.
